# 簡易ユーザーテストの手順(§10)

目的:企画書・ES に数字で載せられるよう、次の3つを記録する。
1. **意図したポーズが選ばれた割合**(判定の精度)
2. **ガイドで迷った箇所**(ステップごとの所要時間+観察メモ)
3. **離脱点**(途中でやめた場所)

対象:友人など数名〜10名。1人あたり 10 分程度。

## 準備(記録係)
1. 判定サーバーを起動する(判定結果と骨格は `data/judge_log/` に自動で記録される。画像は保存しない)。
   ```
   cd C:\PoseSync_Studio\server
   .venv\Scripts\python app.py
   ```
2. Unity で `Booth.unity` を開き、`Booth` オブジェクトの **SessionLogger** を確認する。
   - `participant`:最初の参加者 ID(例 `P01`)。待機画面で **N キー**を押すと次の番号に進む。
   - `note`:グッズの有無などのメモ(Play 中に書き換えてよい)。
3. Play して **F1** キーで左下のステータスを表示する。`記録 P01` と出ていれば記録される(録画する時は F1 で隠す)。

## 同意をとる(参加者ごと)
- 撮影した写真と判定ログは**この PC の中だけ**に保存し、公開しない(`data/` は GitHub に上げない)。
- 企画書・ES に載せるのは**集計した数字だけ**。写真を載せる場合は別途許可をとる。
- 終わったら、希望があれば写真を削除する(`data/photos/`)。

## 進め方(1人あたり)
1. **説明は最小限にする**:「タレントと一緒に写真が撮れるブースです。画面の指示に従ってください」とだけ伝える(ガイドで迷うかを見るため)。
2. **自由に1〜2回**体験してもらう。記録係は口を出さず、迷った様子・発言をメモする。
3. **ポーズを指定して各1回**:「ハート」「大きなハート」「両手ピース」「ピース」と、「どれでもないポーズ」を1回ずつ。
4. **結果画面で、記録係が数字キーを押す**:参加者が**とったつもりの**ポーズを入力する(判定結果ではない)。
   - `1` ハート / `2` 大きなハート / `3` 両手ピース / `4` ピース / `0` どれでもない
   - 自由体験の回は、終わった後に「何のポーズをしましたか?」と聞いてから押す。
   - 押すと左下の表示が `意図:heart_half` などに変わる。押し忘れた回は正解率の集計から外れる。
   - 続けて撮る時は結果画面の「もう一度」(立ち位置ガイドから撮り直し)、その人の体験を終える時は「終了する」(あいさつの後スタート画面へ)。
5. 体験の途中でやめた場合は、記録係が **Esc** を押す(アプリが終了し、どこでやめたかが記録される)。もう一度 Play して続ける。
6. 終わったら、スタート画面で **N** を押して次の参加者へ。

※ 立ち位置ガイドでは、両肩・両肘が枠に入って 2.5 秒たつと自動で撮影へ進む(判定サーバーが動いていない時だけ「撮影開始！」ボタンが出る)。

### 観察メモの観点
- 立ち位置の枠に収まるまでに迷ったか(①立ち位置)
- 見本を見てポーズを決められたか、見本の切り替えが速すぎ/遅すぎないか(②見本)
- カウントダウン中にポーズを崩していないか(③カウントダウン)
- 結果を見た時の反応(タレントの応答ポーズに気付いたか)
- グッズ(ペンライト・うちわ等)を持っている時の判定・切り抜き

## 集計
```
cd C:\PoseSync_Studio\server
.venv\Scripts\python tools\analyze_sessions.py
```
→ `docs/user_test.md` に、正解率・混同行列・ステップの所要時間・離脱点・閾値を変えた場合の正解率が出る。
日付や参加者で絞る時は `--date 20261023` / `--participant P0`、時間帯で絞る時は `--since 2026-10-23T00:00 --until 2026-10-23T01:15`
(開発中の動作確認も同じ記録ファイルに残るので、テストの時間帯で絞ると本番の結果だけになる)。

閾値やテンプレートを変えたら、同じコマンドで判定ログの骨格から再計算できる(撮り直し不要)。
